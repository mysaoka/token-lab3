# Лабораторная работа 3 — ERC-20

Репозиторий: https://github.com/mysaoka/token-lab3

Основа: Laboratornaya_rabota_3_expanded_and_enhanced.pdf. Контракт реализует IERC20 и IERC20Metadata вручную, как в методичке.

Верифицированный контракт в Ethereum Sepolia:
https://sepolia.etherscan.io/address/0xd3206321bdcbe343eac32bf0fde4a5a93008eabc#code

KWNcoin (KWN), decimals = 18, начальный выпуск — 100 000 KWN.

## Запуск интерфейса

Запустить Start_UI.cmd, дождаться Ready и открыть http://localhost:3001 в Chrome с MetaMask. Окно сервера оставить открытым.

1. Нажать «Подключить MetaMask», разрешить подключение учебного аккаунта и переключение в Sepolia.
2. Проверить баланс и роль. Владелец видит форму чеканки.
3. Нажать «Добавить токен в MetaMask» и подтвердить добавление.
4. Для перевода указать публичный адрес получателя и количество KWN (например, 1.5). Нажать «Перевести» и подтвердить в кошельке. После подтверждения обновляется баланс, доступна ссылка на транзакцию.
5. Для чеканки владелец указывает получателя и количество новых KWN. После подтверждения увеличиваются баланс получателя и общий выпуск.
6. При смене аккаунта заново подключить кошелёк. У другого пользователя форма чеканки скрыта. Контракт также проверяет права, независимо от интерфейса.

Суммы переводятся в минимальные единицы с учётом decimals через BigInt, без потери точности Number. Секреты в интерфейсе не используются: операции подписывает MetaMask.

## Проверки и этапы

Из token-contract: `npx hardhat test`.
Подготовленные этапы переключаются из этой же папки: `node ../scripts/set-stage.mjs 1`, `2` или `3`. Команда заменяет Token.sol и Token.ts подготовленной версией. После публичного развёртывания используется этап 3.

1 — исходный контракт с нулевым балансом создателя; 2 — выдача начального выпуска и Transfer; 3 — owner, transferOwnership, mint и проверки ERC-20.

В методичке totalBalance обозначает фактическую переменную totalSupply. Для установленного Hardhat используется network.create(). При сетевых обрывах дополнительный локальный плагин повторяет только запросы чтения, не отправку транзакций. Ключи задаются через Hardhat keystore.

## Место на диске

Текущая папка token-ui/node_modules использует зависимости ЛР2 через junction на D:/Lab2_Poster/poster-ui/node_modules. Не удаляйте зависимости ЛР2, пока работаете с этой копией ЛР3. Установка новых пакетов через этот junction изменит общие зависимости; она для запуска не нужна.

В отдельной копии из репозитория без junction установить зависимости: `npm ci` в token-contract и token-ui. Затем `npm run dev` в token-ui. Публичный адрес и ABI уже включены; секреты в репозиторий не добавляются.
